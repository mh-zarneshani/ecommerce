# دفتر فروش اکتیو

برای ادامهٔ توسعه توسط Code Agent، ابتدا [HANDOFF.md](HANDOFF.md) را بخوانید.

در ویندوز روی **Start-Windows.cmd** دوبار کلیک کنید. سامانه در **http://127.0.0.1:8765/** باز می‌شود. داشبورد، میز پیگیری، ثبت فروش، گزارش‌ها و تنظیمات همگی در همین صفحه هستند. اجرای دوبارهٔ راه‌انداز، همان سامانه را باز می‌کند. پنجرهٔ راه‌انداز تا پایان کار باز بماند.

اگر قبلاً PostgreSQL پروژه را راه‌اندازی کرده‌اید، همان دیتابیس استفاده می‌شود. در اولین راه‌اندازی، برنامه پورت نصب موجود را تشخیص می‌دهد و فقط در صورت نیاز، نام مدیر و رمز او را در ورودی مخفی می‌گیرد. پروفایل برنامه در `%LOCALAPPDATA%\ActiveEcomBootcamp` است؛ رمز مدیر ذخیره نمی‌شود. فایل اکسل اصلی فقط خوانده می‌شود.

۱. در نقش **مدیر**، از «گزارش‌ها و تاریخچه» یک‌بار **ورود اکسل آموزشی** را بزنید. به داشبورد برگردید؛ برش دیجی‌کالا، ۱۵ بهمن، ساعت ۱۸، فقط اکسل، **۲٬۴۱۶ بسته** نشان می‌دهد.

۲. در «ثبت و اصلاح فروش»، دیجی‌کالا، شفاف ۴۵۰ گرمی و ۱۶ بهمن را انتخاب کنید. **۲۰ بسته** به همراه لغو و مرجوعی صفر وارد کنید. قیمت و درصدها را بررسی کنید و «ثبت فروش فرضی» را بزنید. «مشاهده گزارش همین ثبت» نمای ترکیبی را باز می‌کند. برای اصلاح، همان ردیف را دوباره باز کنید، ۱۸ بسته وارد کنید و اصلاح را تأیید کنید. در دیتابیس بدون ثبت فرضی دیگر، جمع ترکیبی از **۲٬۴۳۶** به **۲٬۴۳۴** می‌رسد. «فقط اکسل» جمع اولیه را نگه می‌دارد.

۳. در «میز پیگیری»، «اکسل» و «دموی ساختگی» مجموعه‌های جدا هستند. برای پرونده‌های اکسل مدیر می‌تواند بررسی تا برش را اجرا کند. برای دمو، «شروع دموی ساختگی» را بزنید، در فیلتر فروشگاه «همهٔ اکانت‌های مجاز» را انتخاب کنید و پرونده را باز کنید. دو مسیر «دوباره قابل سفارش شد» و «دریافت اطلاعات خطا داد» از هم مستقل‌اند؛ مسیر دیگر پس از بازنشانی همان دادهٔ آموزشی در دسترس است. ارجاع با تأیید انسان ثبت می‌شود. پس از شاهد معتبر، فقط کارشناس مسئول همان اکانت می‌تواند پرونده را ببندد.

۴. در داشبورد یا در کارت پرونده، پنل «پرسش از هوش مصنوعی» را باز کنید. یک پیشنهاد یا «سؤال دیگر بنویسم» را انتخاب کنید. پیش‌نمایش داده و مقصد قبل از «تأیید و ارسال» نمایش داده می‌شوند. بدون کلید یا در گزارش اکسل، دستیار آفلاین است و پاسخ ساختگی نشان نمی‌دهد. فقط دادهٔ دموی ساختگی می‌تواند پس از تأیید ارسال شود. تاریخچهٔ مدل در نشست همان صفحه و زمینهٔ همان گزارش یا پرونده باقی می‌ماند.

## تنظیم اتصال

در اجرای محلی نقش «مدیر سیستم» را از بالای صفحه انتخاب کنید. در «تنظیمات هوش مصنوعی» می‌توانید GapGPT، AvalAI یا DeepSeek را انتخاب کنید و Base URL مجاز، Model ID و کلید را وارد کنید. این نقش برای اجرای آموزشی ویندوز شبیه‌سازی شده؛ در VPS نقش از هویت تأییدشدهٔ پراکسی می‌آید. برنامه در Windows کلید محلی را با DPAPI برای همان کاربر Windows رمزگذاری می‌کند. کلید از API تنظیمات به مرورگر بازگردانده نمی‌شود. ذخیرهٔ تنظیمات تماسی با سرویس ندارد. «بررسی اتصال» و «آزمایش مدل» هر کدام پیش‌نمایش و تأیید مستقل دارند. برای ورود کلید از همان کادر رمزدار استفاده کنید.

GapGPT به‌صورت پیش‌فرض با `https://api.gapgpt.app/v1` تنظیم می‌شود؛ مدل پیش‌فرض تأییدنشده ندارد و شناسهٔ مدل باید صریحاً از اطلاعات حساب انتخاب شود. مشاهدهٔ فهرست مدل‌ها موفقیت درخواست تکمیل متن را ثابت نمی‌کند. آزمون‌های خودکار از Mock استفاده می‌کنند. برای تنظیم امن Linux و افزودن ارائه‌دهندهٔ سازگار مورد تأیید اپراتور، [راهنمای میزبانی](deploy/README.md) را ببینید.

## اجرا و آزمون

- در macOS و Linux با Python 3.11 و PostgreSQL نصب‌شده، وابستگی‌ها را با `python -m pip install -r requirements.txt` نصب کنید. برای راه‌اندازی اولیه `python setup_local.py --port PORT` را با پورت شناسایی‌شده و سپس `python web_app.py` اجرا کنید. برنامه به‌طور پیش‌فرض روی loopback است.
- آزمون با دیتابیس مجزای پروژه: `python -B -m pytest -q`. برای یک خوشهٔ موقت مستقل: `python qa/run_tests.py -- -q`. در ویندوز از Python همان محیط مجازی استفاده کنید. دیتابیس اصلی را به‌عنوان دیتابیس تست تنظیم نکنید.
- واحد فروش بسته و واحد حمایت تخفیف تومان است. هدف در سطح ماه و اکانت و فروش در سطح اکانت، محصول و روز است. نبود ردیف فروش به معنی صفر نیست. خوانندهٔ اکسل و منبع آزمایشی آفلاین از سرویس ورودی مشترک استفاده می‌کنند.
- فایل‌های قدیمی Streamlit برای تطبیق و آزمون عقب‌گرد در پوشه باقی مانده‌اند. مسیر اصلی همین راه‌انداز است. میان‌برهای CMD قدیمی حذف شده‌اند؛ میان‌برهای شخصی را به `Start-Windows.cmd` تغییر دهید. نصب اولیه یا تعمیر پیکربندی با `Start-Windows.cmd --setup` انجام می‌شود. فایل‌های کمکی داخلی در `scripts/windows` هستند.
